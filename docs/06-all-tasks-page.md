# Страница «Все задачи»

Связан с [01-scope.md](01-scope.md), [02-scenarios-and-permissions.md](02-scenarios-and-permissions.md), [04-task-card.md](04-task-card.md), [05-create-task-dialog.md](05-create-task-dialog.md). Макеты: [wireframes/all-tasks/](wireframes/all-tasks/) (`list.svg` — таблица, `filters.svg` — фильтры, `states.svg` — состояния).

## 1. Назначение и доступ
Список всех неархивных задач проекта, включая бэклог, независимо от досок. Основной инструмент поиска и обзора: фильтры, сортировка, пагинация.
- Маршрут: `/p/PROJ/tasks`; открывается из переключателя видов (раздел «Списки»).
- Просмотр: все роли проекта (`task-view`). «+ Задача»: `task-create`. Пункт «Архивные» в фильтре статуса: `task-restore` (admin и owner).

## 2. Раскладка
1. **Панель:** переключатель видов, поиск по названию и ключу, кнопка «+ Задача».
2. **Строка фильтров:** Статус, Исполнитель, Ревьюер, Приоритет, Тип, Направление (если у проекта есть направления), Теги; на кнопке показывается выбранное («Статус · 2»); справа ссылка «Сбросить», когда фильтры активны.
3. **Таблица.** Колонки: раскрытие (стрелка) · Тип и Ключ · Название (под ним теги, рядом число подзадач) · Статус · Приоритет · Исполнитель · К дате · Направление · Оценка · Затрачено · Обновлено.
4. **Подвал:** «Показано X–Y из N», номера страниц, размер страницы.

## 3. Поведение
**Что в строках.** Только Task и Bug. Подзадачи в строки не попадают, они видны при раскрытии. Строка попадает в список, если подходит она сама или любая её подзадача (поэтому фильтр «Исполнитель = Я» находит задачу, у которой на вас назначена только подзадача).

**Раскрытие.** Стрелка слева есть только у задач с подзадачами; рядом с названием маленькое число подзадач. По клику загружаются все подзадачи задачи (фильтры на них не действуют); пока идёт загрузка, внутри строки показывается индикатор. Подзадачи выводятся в тех же колонках, что и родитель, отсортированы по ключу, фон строк чуть темнее. Состояние раскрытия не хранится в адресе и сбрасывается при смене страницы или фильтров.

**Поиск.** По названию (по вхождению, без учёта регистра); по ключу — только запрос вида номера: `12`, `-12` или `KEY-12` (находит `DEMO-12` и задачи с «12» в названии), иначе только по названию: «de» не находит весь проект `DEMO`. Находит и задачи, у которых совпала подзадача.

**Фильтры.**
- Каждый фильтр многозначный (подходит любое выбранное значение), между фильтрами условие «И».
- Исполнитель и Ревьюер: первый пункт «Я», затем «Не назначен» и участники проекта; есть поиск по участникам.
- Статус: статусы проекта; отдельным пунктом «Архивные» (только при `task-restore`). «Архивные» — взаимоисключающий пункт: выбор «Архивных» снимает выбранные статусы, выбор обычного статуса снимает «Архивные»; смешанного набора нет, и в запросе `archived=true` не бывает `status`.
- Приоритет: Low / Medium / High / Critical. Тип: Task / Bug; относится только к самой строке, подзадачи по типу не проверяются ([backend/05](backend/05-links-search-list.md), раздел 5). Направление и Теги: справочники проекта (у тегов поиск); последним пунктом направления идёт «Без направления» (`none`).
- Фильтры, поиск, сортировка и страница хранятся в адресе: `/p/PROJ/tasks?q=...&status=...&assignee=me&sort=updatedAt:desc&page=2&size=25` (открытая задача добавляет `&task=PROJ-123`). Любое изменение фильтров, поиска или сортировки возвращает на первую страницу.

**Сортировка.** Только по колонкам, где она полезна: Ключ, Приоритет, К дате, Обновлено. По умолчанию «Обновлено» по убыванию. Клик меняет направление, третий клик возвращает порядок по умолчанию. Задачи без срока при сортировке по «К дате» всегда внизу.

**Пагинация.** Серверная. Размеры страницы 10 / 25 / 50, по умолчанию 25. Счёт идёт по строкам Task и Bug (подзадачи в число не входят). Бесконечной ленты нет: нужна ссылка на конкретную страницу и возврат к месту после открытия карточки.

**Обновление данных.** Список перезапрашивается при возврате на вкладку и после своих действий (создание, правка, закрытие карточки); автообновления по таймеру нет.

**Строка.**
- «К дате» красным и с иконкой часов, если срок прошёл и задача не закрыта.
- «Оценка» и «Затрачено» показывают собственные значения задачи (суммы по подзадачам только в карточке); пустые значения «—» (нулевое «Затрачено» тоже «—»).
- Исполнитель: аватар и имя либо «не назначен».
- Одинарный клик по строке выделяет её, двойной клик (или Enter у выделенной строки, или одинарный клик по ключу) открывает карточку задачи в боковой панели: к адресу списка добавляется параметр `?task=PROJ-123` (`/p/PROJ/tasks?...&task=PROJ-123`); после закрытия параметр убирается и остаётся тот же список с теми же параметрами. Двойной клик по подзадаче открывает её карточку.

## 4. Состояния
Загрузка (индикатор поверх таблицы); в проекте нет задач («Задач пока нет», кнопка «+ Задача» при `task-create`); фильтры ничего не нашли («Ничего не найдено», «Сбросить»); роль viewer (нет «+ Задача»); загрузка подзадач в раскрытой строке; режим «Архивные» (пометка «в архиве» у строк, восстановление в карточке). Ошибки сети и сервера показываются общим сообщением приложения с «Повторить», отдельных экранов нет. Подробно: `wireframes/all-tasks/states.svg`.

## 5. API
Группы OpenAPI: Tasks (список и подзадачи). Контракт — [backend/openapi/openapi.yaml](backend/openapi/openapi.yaml); ТЗ — [backend/05-links-search-list.md](backend/05-links-search-list.md).
- Список — `GET /projects/:projectId/tasks` с фильтрами, сортировкой и страницами; подзадачи раскрываются отдельным запросом `GET /tasks/:id/subtasks` с теми же полями, что у строки списка.
- Значения «Я» и «Не назначен» передаются явными кодами (`me`, `none`); фильтры с несколькими значениями — через запятую; архивные — `archived=true` вместо пункта в `status`; условие по подзадачам реализует бэкенд.
- Источники значений фильтров: статусы, участники, направления, теги (поиск по `search`); приоритеты и типы фиксированные.

## 6. Сценарии
- **L1 Открыть список:** последние обновлённые задачи, 25 на странице.
- **L2 Найти задачу:** ввод названия или номера (`12`, `DEMO-12`).
- **L3 Отфильтровать:** выбрать значения в нескольких фильтрах, «Сбросить».
- **L4 «Мои задачи» и «на ревью у меня»:** Исполнитель или Ревьюер = «Я».
- **L5 Отсортировать** по приоритету, сроку, ключу.
- **L6 Перейти по страницам**, поменять размер страницы.
- **L7 Раскрыть задачу** и посмотреть подзадачи; открыть подзадачу.
- **L8 Открыть карточку** и вернуться к тому же списку.
- **L9 Создать задачу:** «+ Задача» → диалог → открывается карточка.
- **L10 Архивные (admin/owner):** выбрать «Архивные» в статусе, открыть задачу, восстановить.
Соответствие M15 из документа 02.

## 7. Оценка трудозатрат фронта: ≈ 50 ч
Таблица и колонки 8; сортировка 4; поиск 3; компонент фильтров (семь фильтров, синхронизация с адресом, общий с досками, делается первой задачей этапа) 16; пагинация и адрес 6; раскрытие с подгрузкой 8; состояния 4; права и вёрстка 1. Без общего компонента фильтров ≈ 35 ч.

## 8. Открытые вопросы
- Адаптив таблицы: 10 колонок, на узких экранах горизонтальная прокрутка с закреплёнными колонками «Ключ» и «Название» (решить по дизайну).
- Нужны ли суммы по подзадачам в колонках «Оценка» и «Затрачено» (сейчас только собственные значения).
- Решено (Q-05, I-19): сохранённых фильтров и запоминания последнего набора между сессиями нет, фильтры живут только в адресе; запоминается последний использованный вид ([11](11-navigation-and-notifications.md), раздел 4).

## Приёмка
Формат и сид — как в [04](04-task-card.md), раздел «Приёмка». В `DEMO` не меньше 60 задач ([backend/05](backend/05-links-search-list.md), §6). Роль с правом: `clara_member` (просмотр, `task-create`), `boris_admin` (admin, `task-restore`); `eva_viewer` — viewer.

**L1 Открыть список** (M15)
- L1.1 Дано: `clara_member`. Действие: «Списки» → «Все задачи». Ожидаю: адрес `/p/DEMO/tasks`, сортировка «Обновлено» по убыванию, 25 строк, «Показано 1–25 из N», только Task и Bug, архивных нет.
- L1.2 Дано: `eva_viewer`. Ожидаю: тот же список, кнопки «+ Задача» нет.
- L1.3 Дано: проект `SIMPLE` без выбранных фильтров. Ожидаю: 5 задач, подвал «Показано 1–5 из 5».

**L2 Найти задачу**
- L2.1 Дано: список в проекте `DEMO`. Действие: ввести часть названия в другом регистре; ввести ключ `DEMO-3`; ввести `3`; ввести `de`. Ожидаю: нужные строки; `DEMO-3` и `3` находят задачу `DEMO-3` (и задачи с «3» в названии); `de` находит только задачи с «de» в названии, а не весь проект; адрес содержит `q=`; страница сброшена на первую.
- L2.2 Дано: задача, у которой совпала только подзадача. Действие: ввести её название. Ожидаю: родитель в результатах.
- L2.3 Дано: текст без совпадений. Ожидаю: «Ничего не найдено», кнопка «Сбросить».

**L3 Отфильтровать**
- L3.1 Дано: список. Действие: Статус = 2 значения. Ожидаю: кнопка «Статус · 2», строки с любым из значений, «Сбросить» появилось.
- L3.2 Дано: фильтры Приоритет и Направление. Ожидаю: условие «И» между фильтрами, «ИЛИ» внутри.
- L3.3 Дано: фильтры включены. Действие: перезагрузить страницу или открыть адрес в новой вкладке. Ожидаю: те же фильтры и страница.
- L3.4 Дано: страница 2. Действие: изменить любой фильтр. Ожидаю: возврат на страницу 1.
- L3.5 Дано: фильтры. Действие: «Сбросить». Ожидаю: фильтры очищены, параметры из адреса убраны.
- L3.6 Дано: фильтры дали ноль строк. Ожидаю: «Ничего не найдено» и «Сбросить».
- L3.7 Дано: Тип = Bug. Ожидаю: в строках только Bug; подзадачи по типу не проверяются.
- L3.8 Дано: проект с направлениями. Действие: открыть фильтр «Направление». Ожидаю: значения проекта и последним пунктом «Без направления»; выбор показывает задачи без направления. В проекте без направлений (`SIMPLE`) фильтра и колонки нет.

**L4 «Мои задачи» и «на ревью у меня»**
- L4.1 Дано: `clara_member`. Действие: Исполнитель = «Я». Ожидаю: задачи, где она исполнитель или у которых на неё назначена подзадача.
- L4.2 Дано: Ревьюер = «Я». Ожидаю: задачи на ревью у `clara_member` из сида.
- L4.3 Дано: Исполнитель = «Не назначен». Ожидаю: только задачи без исполнителя. В списке выбора есть поиск по участникам; деактивированный `fedor_inactive` показан серым «(деактивирован)» (в фильтре он нужен, чтобы найти его задачи).

**L5 Сортировка**
- L5.1 Дано: список. Действие: клик по «К дате», ещё клик, ещё клик. Ожидаю: по возрастанию, по убыванию, порядок по умолчанию; задачи без срока всегда внизу.
- L5.2 Дано: колонки «Ключ», «Приоритет», «Обновлено». Ожидаю: сортируются; по остальным колонкам клик не сортирует. Сортировка в адресе, изменение сбрасывает страницу на первую.

**L6 Страницы**
- L6.1 Дано: 60+ задач. Действие: размеры 10, 25, 50; страница 2; ссылка на страницу 2 в новой вкладке. Ожидаю: подвал и строки соответствуют; счёт идёт по Task и Bug; ссылка открывает ту же страницу.
- L6.2 Дано: смена размера страницы. Ожидаю: возврат на страницу 1.

**L7 Раскрыть задачу**
- L7.1 Дано: задача с подзадачами. Действие: стрелка. Ожидаю: индикатор внутри строки, затем все подзадачи (фильтры на них не действуют), по ключу, тот же набор колонок, фон темнее. У задач без подзадач стрелки нет, рядом с названием число подзадач.
- L7.2 Дано: раскрыто. Действие: сменить фильтр или страницу. Ожидаю: раскрытие сброшено.
- L7.3 Дано: двойной клик по подзадаче. Ожидаю: открылась её карточка.

**L8 Открыть карточку и вернуться**
- L8.1 Дано: фильтры и страница 2. Действие: одинарный клик по строке, затем двойной клик, Enter, клик по ключу. Ожидаю: одинарный выделяет; остальные открывают панель, адрес списка получает `task=DEMO-N` (фильтры и страница в адресе остаются).
- L8.2 Дано: панель открыта. Действие: закрыть, изменить поле, закрыть. Ожидаю: тот же список с теми же параметрами, изменение видно.
- L8.3 Дано: задача с просроченным сроком. Ожидаю: «К дате» красным с иконкой; «Оценка» и «Затрачено» собственные, пустые и нулевые «—», исполнитель — аватар и имя либо «не назначен».

**L9 Создать задачу**
- L9.1 Дано: `clara_member`. Действие: «+ Задача» → название → «Создать». Ожидаю: открылась карточка; после закрытия задача в списке (при сортировке по умолчанию — вверху).
- L9.2 Дано: проект без задач (создать новый). Ожидаю: «Задач пока нет» и «+ Задача» у роли с `task-create`; у `eva_viewer` кнопки нет.

**L10 Архивные**
- L10.1 Дано: `boris_admin`. Действие: Статус → «Архивные». Ожидаю: только архивные задачи, пометка «в архиве»; открыть, «Восстановить» → задача вернулась в обычный список.
- L10.4 Дано: выбраны «Архивные», затем статус Done. Ожидаю: «Архивные» снялись, список обычный со статусом Done; если сначала Done, затем «Архивные» — Done снят, показаны только архивные задачи.
- L10.2 Дано: `clara_member` и `eva_viewer`. Ожидаю: пункта «Архивные» в фильтре статуса нет.
- L10.3 Дано: остановлен бэкенд. Действие: открыть список. Ожидаю: общее сообщение с «Повторить»; индикатор загрузки поверх таблицы виден до ответа.
